## F5 — `destroyBrick` n'est pas idempotent : `bricksRemaining` peut passer sous 0 et rendre la victoire inatteignable — et un test ratifie le défaut

L'aggravant est dans les tests : `logic.test.mjs:98-109` assert explicitement `bricksRemaining === initial - 2` après double destruction, avec le commentaire `// This test documents the current behavior`. *Honnêteté sur l'atteignabilité* : `tick()` protège la boucle briques par `!brick.destroyed` (`:132`), donc le chemin nominal ne double-détruit pas. La faille est une rupture d'invariant latente, exposée à tout appelant externe et verrouillée par un test.

## F6 — `reflectBall('collision')` : branche redondante, et aucune réflexion sur l'axe X lors d'un impact latéral

**Angle** : zone morte + écart contrat/code sur R3 « rebond conservatif ».

**Faille** : `engine.mjs:148-156` — la branche `mode === 'collision'` (`:153-155`) exécute **exactement** le corps de la branche `'y'` (`:151-152`). C'est un chemin de code sans comportement propre. La conséquence de jeu est réelle : `tick()` appelle `reflectBall('collision')` pour **tout** contact balle-brique (`:134`), quelle que soit la géométrie de l'impact. Une balle qui percute la **face latérale** d'une brique se voit inverser `vy` au lieu de `vx` : elle conserve son sens horizontal et continue de traverser la rangée. L'oracle E3 ne peut pas l'attraper — il vérifie que `reflectBall` inverse le signe et conserve `|v|` **pour l'axe qu'on lui passe en paramètre**, jamais que le bon axe est choisi pour une géométrie d'impact donnée (`logic.test.mjs:58-84` et `:175-187`, ce dernier assertant précisément l'équivalence `'collision' ≡ 'y'`).

**Sévérité** : **MEDIUM**

**Reproduction** :
```bash
cd GAMES/runm_breakout
node -e "import('./engine.mjs').then(({Engine})=>{
  // (a) equivalence des branches
  const p=new Engine(); p.ball.vx=7; p.ball.vy=11; p.reflectBall('collision');
  const q=new Engine(); q.ball.vx=7; q.ball.vy=11; q.reflectBall('y');
  console.log('collision === y :', p.ball.vx===q.ball.vx && p.ball.vy===q.ball.vy);
  // (b) impact lateral : le sens horizontal n'est pas inverse
  const e=new Engine({seed:1}), br=e.bricks[0];
  e.ball.x = br.x - 6; e.ball.y = br.y + br.height/2; e.ball.vx = 250; e.ball.vy = 20;
  const sgn = Math.sign(e.ball.vx);
  e.tick(null);
  console.log('brique detruite :', br.destroyed, '| sens vx conserve :', Math.sign(e.ball.vx)===sgn);
});"
```
Attendu : `collision === y : true` et `brique detruite : true | sens vx conserve : true` — la balle détruit la brique par le côté et poursuit sa route horizontale.
